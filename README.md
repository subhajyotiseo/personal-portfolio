# Subhajyoti Karmakar — Personal Portfolio

This is a simple HTML, CSS, and JavaScript portfolio website.

## Project structure

```text
Personal Portfolio/
├── index.html                 Main homepage
├── README.md                  Project instructions
├── assets/
│   ├── css/
│   │   └── styles.css         Colors, layout, fonts, and responsive design
│   ├── js/
│   │   └── script.js          Mobile menu and form interactions
│   ├── images/
│   │   ├── blog/              Images for blog articles
│   │   └── case-studies/      Images for case studies
│   ├── icons/                 Logos and small icons
│   └── documents/             Resume, portfolio PDF, or downloadable files
└── pages/                     Future pages such as About, Blog, and Services
```

## How to open the website

Double-click `index.html`. It will open in your normal web browser.

## The three main files

- `index.html` contains the website content.
- `assets/css/styles.css` controls how the website looks.
- `assets/js/script.js` controls interactive features.

## Before publishing

1. Add your profile photograph inside `assets/images`.
2. Review the profile and resume content and confirm that every result is accurate.
3. Add published blog articles when they are ready.
4. Test the email, social profiles, resume download, and navigation links.
5. Publish the website when everything has been reviewed.

Keep file and folder names lowercase and avoid spaces when adding new files.
